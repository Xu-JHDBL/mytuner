# MyTuner 调音器

一个极简、免费的网页版调音器，支持**吉他**与**贝斯**标准调弦，适合日常校音。

## 在线使用

👉 **https://xu-jhdbl.github.io/mytuner/**

（手机 Safari / Chrome 直接打开即可，无需安装）

> ⚠️ 调音器需要用到麦克风，浏览器要求**安全上下文**（HTTPS 或 localhost）。
> 上面这个 GitHub Pages 地址是 HTTPS，可以直接用；如果本地双击打开 `index.html`，
> 麦克风会被浏览器禁用，请改用本地服务器（见下方「本地使用」）。

## 功能

- 支持乐器：吉他（E A D G B E）、贝斯（E A D G）
- **先选乐器、再选要调的那根弦**，针对该弦工作
- 实时音高检测 + 音名 / 八度 / 音分显示
- 指针表盘，绿色区域表示「已调准」（±5 音分）
- 调准后点「标记调音完成」，该弦按钮加一层半透明绿 ✓

## 使用流程

1. 顶部选**乐器**（吉他 / 贝斯）
2. 点选要调的**弦**（如「5弦 A2」）
3. 点「开始」允许麦克风，靠近琴弦拨**单根**弦
4. 看指针：偏左偏低、偏右偏高，指针入中间**绿色区**即调准
5. 点「**标记调音完成**」，该弦按钮变绿；换下一根弦继续

## 本地使用

因为需要麦克风（安全上下文），本地建议起一个静态服务器：

```bash
# 在 MyTuner 目录下任选其一
python -m http.server 8000
# 或
npx serve .
```

然后浏览器打开 `http://localhost:8000` 即可（localhost 属于安全上下文，麦克风可用）。

## 技术说明

- 音高检测采用**时域自相关（YIN）算法**，配合抛物线插值做到亚采样精度；
  相比 FFT，时域自相关对低频（贝斯 E1 ≈ 41 Hz）分辨率更好，无需超大窗口
- 采样经**中值滤波 + 指数平滑**，抑制噪声与偶发的八度跳变，显示更稳定
- 界面零依赖、无版权问题，纯静态页面可直接部署
